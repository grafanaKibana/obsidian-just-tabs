# Security policy

## Supported versions

Until `1.0.0`, only the latest published beta receives security fixes. After `1.0.0`, the latest stable release is supported.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/grafanaKibana/obsidian-just-tabs/security/advisories/new). Do not open a public issue for a vulnerability.

Include the affected version, impact, reproduction steps, and the smallest safe proof of concept. Remove vault contents, paths, and personal information.

Just Tabs is designed to operate locally without telemetry, network requests, external accounts, or access outside the Obsidian vault.
